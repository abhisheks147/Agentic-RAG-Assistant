
🚀 Agentic RAG Assistant

A Multi-Agent Retrieval-Augmented Generation (RAG) Assistant powered by Google Gemini that enables users to upload documents, build a knowledge base, and interact with it using natural language queries. The system retrieves relevant information from uploaded documents and generates accurate, context-aware responses.

📌 Overview

Agentic RAG Assistant is designed to simplify document analysis and knowledge retrieval. Users can upload PDF documents, ask questions related to the content, generate summaries, explain concepts, and create study plans. By combining Retrieval-Augmented Generation (RAG) with a multi-agent architecture, the assistant delivers reliable and context-grounded answers.

🏗️ Architecture

The system follows a Retrieval-Augmented Generation workflow:

User uploads a document.
Document is processed and split into chunks.
Embeddings are generated and stored in a vector database.
Relevant document chunks are retrieved based on the user's query.
Multiple agents analyze the retrieved context.
Google Gemini generates a final response using the retrieved information.
